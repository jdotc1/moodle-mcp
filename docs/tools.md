# Tools reference

_Generated by `scripts/gen_tools_doc.py` from the operation registry. Do not edit by hand._

Every tool is available both as an MCP tool and as `POST /api/v1/tools/<name>` in hosted mode. `profile` (optional) selects the institution when you configured several.

Annotations: **R** read-only · **W** writes · **D** destructive hint · **I** idempotent.

## attendance

### `attendance_report`  `[RI]`

[READ] Attendance analysis: registered absences, pending roll calls, frequency so far, absence limit and
margin, hours still needed, how many future meetings can be skipped (weighted), critical meetings, and the
effect of skipping specific dates. min_frequency is REQUIRED per course (e.g. '75%') with its source (syllabus
/ regulation): the server never assumes it. Moodle's Attendance points/percentage is not official presence.

| Parameter | Required | Description |
| --- | --- | --- |
| `course_id` | yes | course id. |
| `min_frequency` | no | minimum frequency rule such as '75%'. |
| `rule_source` | no | where the rule comes from (syllabus section, regulation + date). |
| `total_hours` | no | official total class-hours of the course, if known (otherwise limits are provisional). |
| `hours_per_session` | no | class-hours each meeting counts (e.g. 2). |
| `minutes_per_hour` | no | minutes per class-hour when deriving weights from session duration (e.g. 50). |
| `source` | no | 'moodle' (Attendance service), 'manual' (imported by attendance_import_manual) or 'auto'. |
| `attendance_id` | no | Attendance instance id if the course has several. |
| `late_counts_as` | no | how 'late' counts. |
| `excused_counts_as` | no | how justified absences count (excluded = removed from the total). |
| `skip_dates` | no | ISO dates of future meetings you consider missing, for the scenario. |
| `assume_future_attended` | no | share (0-1) of remaining hours attended in the projection. |
| `assume_pending` | no | how to treat past sessions without a recorded roll call. |

Moodle functions: `mod_attendance_get_sessions` (read; upstream_mod_attendance), `mod_attendance_get_session` (read; upstream_mod_attendance), `core_webservice_get_site_info` (read; ufsc_mobile)

### `required_score`  `[RI]`

[LOCAL] Minimum score needed on one item to reach `target` (default: pass_mark). Reports impossible /
already_met / underdetermined (when other items are still missing: choose fill_others).

| Parameter | Required | Description |
| --- | --- | --- |
| `scheme` | yes | grading scheme as in simulate_grades. |
| `item` | yes | item name to solve for. |
| `target` | no | goal value (default pass_mark). |
| `fill_others` | no | assume other missing items score 0 ('worst') or the max ('best'). |
| `step` | no | search resolution. |

Moodle functions: none (local computation or local data only).
